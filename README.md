# Telecommunication Customer Churn Prediction using ANN

## 📌 Project Overview

This project predicts whether a telecommunication customer will churn or continue using the service.

## 🎯 Objective

The main objective is to identify customers who are likely to leave the company using an Artificial Neural Network (ANN).

## 📊 Dataset

The Telco Customer Churn dataset contains customer information such as:

- Gender
- Senior Citizen
- Tenure
- Contract
- Internet Service
- Monthly Charges
- Total Charges
- Churn

## 🤖 Model Used

- Artificial Neural Network (ANN)
- TensorFlow
- Keras

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

## 📈 Output

The model predicts:

- CHURN
- NO CHURN

## 📂 Files

- `Telecommunication_churn_prediction.ipynb` – Complete Google Colab notebook
- `Telco-Customer-Churn.csv` – Dataset
- `README.md` – Project documentation

## ▶️ How to Run

Open the notebook in Google Colab and run the cells from top to bottom.
